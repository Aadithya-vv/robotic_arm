# TaskGraph v0.1 — Core Platform

First runnable local desktop release of TaskGraph.

Highlights include seven composed Core Platform Engines, live health/status display, activity timeline, validation controls, report export, graceful shutdown, structured startup failures, and public-contract-only integration.

Known limitations: no Perception or semantic workflow, simulation, durable log sink, persistent memory, or packaged installer. The next milestone begins with architect-authorized ENG-008 Camera Engine work after M1 review.
