# Repository Guide

The repository is organized by artifact type. Every Engine has matching, uniquely named folders across Specifications, Prompts, Implementation, Reports, Documentation, and Tests.

- Specifications contain requirements and acceptance criteria.
- Contracts contains repository-level architectural contracts shared across Engines. It is not an Engine and contains no implementation.
- Prompts authorize future implementation of one Engine.
- Implementation contains empty Source workspaces.
- Reports contain Implementation Report templates.
- Documentation contains Engine navigation and later documentation.
- Tests contains empty test workspaces.
- Research and Assets hold their ABP-defined artifact classes.

Never duplicate an artifact in another workspace. Navigate through RepositoryManifest.md and the indexes.
