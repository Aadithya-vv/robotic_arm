# Architecture Overview

Human Demonstration → Camera Observation → Vision Understanding → Scene Understanding → Semantic Inventory → Knowledge Representation → Affordance Reasoning → Task Planning → TaskIR Generation → Execution → Simulation → Replay → User Feedback

The seven layers are Observation, Perception, Semantic, Knowledge, Planning, Execution, and Feedback. Twenty-four independent Engines realize them across six domains.

Core principles are semantic before motion, understand before acting, explainability, progressive intelligence, human validation, independent Engines, interface-based communication, local-first operation, and simulation-only Version 1 execution.

ABP/ and GBP/ remain authoritative.
